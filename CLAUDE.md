# Weft Core Guidelines
- To explore code, call the `weft_context` / `weft_search` MCP tools (CLI: `weft context "<query>"`) before grepping or reading whole files; use `weft_read` for exact line ranges.
- Checkpoints are saved automatically; only run `weft task start <title>` to name a long task.
